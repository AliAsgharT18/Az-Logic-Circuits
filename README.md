## Az-Logic-Circuits

مجموعه گزارش‌های آزمایشگاه مدارهای منطقی (Digital Logic Circuits Lab) شامل پنج آزمایش (Az1 تا Az5)، از آشنایی با نرم‌افزارهای شبیه‌سازی مدار (Fritzing، Logisim و Proteus) تا طراحی مدارهای ترکیبی و توالی؛ هر آزمایش شامل گزارش کامل به‌صورت فایل LaTeX/PDF به‌همراه فایل‌های شبیه‌سازی مربوطه است.
